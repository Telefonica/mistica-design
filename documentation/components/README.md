# Mística Components Documentation

_Complete component documentation for the Mística Digital Design System_

## Overview

This folder contains detailed documentation for all Mística components. Each component has its own dedicated file with comprehensive information about usage, anatomy, accessibility, and implementation guidelines.

## Component Categories

### Interactive Components

- **[Accordion](./accordion.md)** - Expandable content sections for organizing information
- **[Avatar](./avatar.md)** - Visual representation of users and entities
- **[Badge](./badge.md)** - Information and notification indicators
- **[Breadcrumbs](./breadcrumbs.md)** - Navigation hierarchy display
- **[Buttons](./buttons.md)** - Action triggers and interactions
- **[Callout](./callout.md)** - Information snippets that draw attention to important content
- **[Checkbox](./checkbox.md)** - Multi-selection form controls for user choices
- **[Chips](./chips.md)** - Interactive elements for selections, filters, and actions
- **[Counter](./counter.md)** - Numeric value adjustment with increment/decrement controls

### Content Components

- **[Cards](./cards.md)** - Grouped content containers with multiple variants (Cover, Media, Data, Naked)
- **[Carousels](./carousels.md)** - Horizontal scrolling components for multiple items
- **[Input Fields](./input-fields.md)** - Text entry components with validation and accessibility

### Layout Components

- **[Primitives](./primitives.md)** - Low-level building blocks (Text, Boxed, Circle, Media)

### Additional Components

_More components are available in the main Mística system. This documentation covers the core components. For a complete list, refer to the main component documentation._

## How to Use This Documentation

Each component document includes:

1. **Overview** - Component purpose and use cases
2. **Anatomy** - Component structure and elements
3. **Behavior** - Interaction patterns and states
4. **Accessibility** - Guidelines for inclusive design
5. **Usage Guidelines** - When and how to use the component
6. **Implementation Notes** - Technical considerations
